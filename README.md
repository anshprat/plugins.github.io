# plugins.anshuprateek.com

Browser extensions for daily work on GitHub, Slack, Google, LinkedIn and more. All of them are open source. Each link goes to the GitHub repository, which has the install steps, the permissions and the privacy policy.

## GitHub

| Extension | What it does | Browsers |
|---|---|---|
| [GitHub Word Diff](https://github.com/anshprat/gh-text-diff) | Highlights only the changed words in long changed lines of a pull request diff, not the whole line. | Chrome |
| [GitHub Markdown WYSIWYG](https://github.com/anshprat/github-md-wysiwyg) | Edits Markdown files on github.com in a rich-text editor, then commits with the normal GitHub flow. | Chrome |
| [GitHub Admin Profile Guard](https://github.com/anshprat/gh-profile) | Shows an alert when you use an admin GitHub profile on a pull request page. | Chrome |
| [GitHub Actions Green Checkboxes](https://github.com/anshprat/GitHub-Actions-Green-Checkboxes) | Changes the grey checkboxes on GitHub Actions detail pages to green, to match the successful steps. | Chrome |

## Sign-in and security

| Extension | What it does | Browsers |
|---|---|---|
| [OAuth Auto-Approver](https://github.com/anshprat/oauth-approver) | Clicks through OAuth consent pages for Google, AWS SSO and Dex. Clicks a passkey page only once. | Chrome, Firefox |
| [Tab Lock](https://github.com/anshprat/tab-lock) | Locks the websites you choose behind a password. It blocks them before they load, and locks them again when you switch away. | Chrome |

## Meetings and planning

| Extension | What it does | Browsers |
|---|---|---|
| [Meet Auto-Join](https://github.com/anshprat/gmeet-autojoin) | Clicks the Join button on the Google Meet pre-join page. An optional list limits it to the meetings you choose. | Chrome |
| [Standup Timer](https://github.com/anshprat/standup-timer) | Shows a configurable standup timer on the page, for example on Linear while you share your screen. | Chrome |
| [Linear for Google Docs](https://github.com/anshprat/linear-gdoc) | Creates Linear issues from the action items in a Google Doc, and keeps the checkboxes and the issue states in sync. | Chrome |

## Slack and LinkedIn

| Extension | What it does | Browsers |
|---|---|---|
| [Slack Emoji Importer](https://github.com/anshprat/slack-emojis-importer) | Adds a search panel to the Slack emoji page. Finds emojis on slackmojis.com and slackemoji.com and adds them to your workspace in one click. | Chrome, Firefox |
| [LinkedIn Connections Exporter](https://github.com/anshprat/linkedin-connections) | Scrolls your LinkedIn connections page and exports the name, profile URL, headline and connected date to CSV. | Chrome |
| [LinkedIn Accept All Invitations](https://github.com/anshprat/linkedin-accept-all) | Accepts all pending LinkedIn connection invitations in one click. | Chrome |

## Admin consoles and tools

| Extension | What it does | Browsers |
|---|---|---|
| [Datadog Startup Pricing Calculator](https://github.com/anshprat/dd-startup-pricing) | Shows estimated on-demand costs on the Datadog usage page, for startup plans where credits hide the total. | Chrome |

## Install

To install an extension from its source:

- **Chrome:** clone the repository, open `chrome://extensions`, turn on Developer mode, click **Load unpacked** and select the folder.
- **Firefox:** follow the Firefox steps in the repository README.
